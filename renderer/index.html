        通知

        Among Usをプレイ中に通知が出ない

        Windowsの「応答不可」が、ゲーム中に自動でオンになっている可能性が高いです。応答不可の間は通知が画面に出ず、通知センター(画面右下の日時をクリック)にだけ入ります。

        「設定」→「システム」→「通知」→「応答不可を自動的にオンにする」で、次のチェックを外してください。

        • ゲームをプレイしているとき
        • 全画面モードでアプリを使用しているとき
        通知がまったく出ない

        次の順に確認してください。

        • 「設定」タブの「新しい部屋が開かれたら通知する」がオンになっているか
        • Windowsの「設定」→「システム」→「通知」で、通知全体と「SNR Room Notifier」がオンになっているか
        • 画面上部が「一時停止中」になっていないか

        「設定」タブの「テスト通知を出す」で確認できます。結果は同じ画面に表示されます。

        アプリを起動したとき、すでに開いていた部屋が通知されない

        起動直後や一時停止から再開した直後は、通知の連発を防ぐため、その時点の部屋を記録するだけにしています。すでに開いている部屋は「部屋」タブの一覧から参加できます。

        部屋が開いてから通知が来るまで少し遅れる

        サーバーの負荷を考えて、部屋の一覧は10秒ごとに確認しています。そのため、通知が最大10秒ほど遅れることがあります。

        満員の部屋に入りたい

        「設定」タブの「満員の部屋に空きが出たら通知する」をオンにすると、募集中で満員だった部屋に空きが出たときに通知します。同じ部屋の通知は2分に1回までです。お気に入り・ミュート・通知の条件も反映されます。

        夜中は通知してほしくない

        「設定」タブの「静かな時間帯は通知しない」をオンにして、時間を指定してください。23:00〜07:00 のように日をまたぐ指定もできます。静かな時間帯の間も監視は続き、部屋は一覧に表示されます(時間帯が明けてからまとめて通知はしません)。

        放置している間にたまった通知を消したい

        閉じた・始まった・満員になった部屋の通知は、自動で通知センターから消えます(「設定」タブでオフにできます)。参加できた部屋の通知も消えます。

        まとめて消すときは、「設定」タブの「通知をすべて消す」か、タスクトレイのアイコンを右クリックして「通知をすべて消す」を選んでください。前回起動したときの通知も消えます。

        通知が1件にまとめられた

        一度に4件以上の部屋が開かれたときは、通知を1件にまとめます。クリックすると一覧が開きます。

        一部の部屋しか通知されない

        「設定」タブの「通知の条件」で、マップ・インポスター・人数・部屋名を絞り込んでいると、条件に合う部屋だけ通知します。「条件をすべて解除」で元に戻せます。

        人数の条件は「その人数に達した時点」で通知します。開いた直後は条件に合わなくても、人が集まれば通知されます。

        非公開の部屋や、自分で立てた部屋は通知される?

        非公開の部屋は一覧に出ないため通知されません。自分で立てた部屋でも、公開していれば通知されます。自分の部屋を通知したくないときは、「設定」タブの「お気に入り・ミュート」で自分の名前をミュートしてください。

        参加

        「参加」を押しても参加できない

        参加するには、SuperNewRolesを入れたAmong Usが起動している必要があります。起動していないときは「設定」タブで選んだAmong Us.exeを自動で起動し、読み込みが終わるのを待ってから参加します。初回はコスメのダウンロードなどで数分かかることがあります。

        参加できる部屋は「募集中」で満員でない部屋だけです。開始中や満員の部屋は「参加」を押せません。

        「すでにゲームに参加しています」と出る

        Among Usがほかの部屋(ロビー)に入っているときや、起動してすぐでまだ読み込み中のときに出ます。部屋から抜けてタイトル画面に戻ってから、もう一度「参加」を押してください。

        Among Us.exe はどこにある?

        SuperNewRolesを入れたフォルダの中にあります。Steamで入れた場合は、たとえば C:\Program Files (x86)\Steam\steamapps\common の中の、SuperNewRolesを入れたAmong Usのフォルダです。

        その他

        画面を閉じたのに動いている / 終了したい

        画面を閉じてもタスクトレイで監視を続けます。完全に終了するときは、タスクトレイのアイコンを右クリックして「終了」を選んでください。

        アップデートのしかた

        新しいバージョンが出ると、画面の上部とタスクトレイのメニューに表示され、通知でもお知らせします(同じバージョンは1回だけ)。ダウンロードページからインストーラーを実行すると、設定を引き継いだまま更新されます。更新前に、タスクトレイのアイコンを右クリックして「終了」してください。

        確認には GitHub の Releases を使い、6時間ごとに確認します。「設定」タブでオフにできます。
